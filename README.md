# 오늘의 나 V5.9.4 — 좌우 스크롤 및 상단 겹침 수정

수정 사항
- 꾸미기 화면 좌우 스크롤 완전 차단
- 모든 편집 영역 너비를 화면 안쪽 100%로 제한
- 96vw 사용으로 생기던 가로 넘침 제거
- 상단 꾸미기 제목 영역이 사진 위에 떠다니지 않도록 sticky 해제
- 세로 스크롤 시 사진이 상단 제목 위로 비쳐 보이던 현상 수정
- 작은 화면에서 버튼과 탭이 화면 밖으로 밀리지 않도록 min-width 보정
- 사진 비율 3:4 유지
- 기존 손그림, 형광펜, 붓, 반짝이, 지우개 기능 유지
