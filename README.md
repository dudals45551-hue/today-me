# 오늘의 나 V5.9.1 — 손그림 삭제 및 조작 버튼 축소

수정:
- 크게/작게/회전/삭제 버튼 높이와 여백 축소
- 손그림 전체 지우기 시 저장된 손그림 데이터도 즉시 삭제
- 빈 손그림 캔버스는 저장하지 않음
- 새로 선택한 사진은 깨끗한 원본을 별도 저장
- 캐릭터 꾸미기는 저장 완료 이미지가 아닌 깨끗한 원본 사진에서 시작
- 새 사진을 선택하면 이전 스티커와 손그림 편집 데이터 초기화
- 홈과 성장앨범 저장 시에만 스티커와 손그림을 최종 합성

중요:
이전 버전에서 손그림이 이미 사진 자체에 합쳐져 저장된 경우에는 픽셀을 자동으로 분리할 수 없습니다.
그 경우 원본 사진을 한 번 다시 선택하면 이후부터는 손그림을 완전히 지울 수 있습니다.
