# 오늘의 나 V6.0.1 — 성장앨범 사진 클릭 수정

수정 사항
- 성장앨범 사진 카드의 터치/클릭 이벤트를 이벤트 위임 방식으로 변경
- 삼성 인터넷에서 동적 버튼 클릭이 무시되는 현상 보완
- 손가락 터치, 펜 입력, 일반 클릭 모두 지원
- 이미지와 날짜 글자가 터치 이벤트를 가로채지 않도록 수정
- 사진 카드에 명확한 터치 영역과 접근성 라벨 추가
- 중복 터치로 전체화면이 두 번 열리는 현상 방지
- 기존 전체화면, 좌우 넘기기, 즐겨찾기, 다시 꾸미기, 공유, 삭제 기능 유지
