# 오늘의 나 V5.9.6 — 최종 꾸미기 사진만 성장앨범 저장

변경 사항
- 메인 화면의 '캐릭터 꾸미기'를 '사진 꾸미기'로 변경
- 사진 선택만으로는 성장앨범에 저장되지 않음
- 꾸미기 저장을 누른 최종 사진만 성장앨범에 저장
- 같은 아이·같은 날짜의 기존 원본/중복 사진을 제거하고 최종 사진 1장만 유지
- 과거에 저장된 같은 날짜 중복 항목도 성장앨범을 열 때 자동 정리
- 성장앨범 사진 수를 실제 최종 사진 개수로 표시
- 저장 완료 문구를 '사진 꾸미기 완료!'로 변경
