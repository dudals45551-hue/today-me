# 오늘의 나 V6.0.0 — 성장앨범 갤러리

추가 기능
- 성장앨범 사진을 누르면 전체화면 크게 보기
- 좌우 화살표 및 손가락 스와이프로 사진 이동
- 즐겨찾기 추가/해제
- 앨범 사진 다시 꾸미기
- 휴대폰 공유 기능
- 성장앨범 사진 삭제
- 날짜와 현재 사진 순서 표시
- 기존 사진 꾸미기, 손그림, 별 잠금, 저장 구조 유지

주의
- 과거 성장앨범 사진은 썸네일로 저장되어 있어 다시 꾸미기 시 원본보다 해상도가 낮을 수 있습니다.
- 새로 저장되는 사진 관리 방식은 기존 로컬 저장 용량 정책을 유지합니다.
