# 하린서율♥︎ V6.2.5 — 성장앨범 사진과 아빠의 편지

변경 사항
- 아빠의 편지를 아이별·날짜별로 성장앨범에 저장
- 부모님 설정에서 편지를 저장할 날짜 선택 가능
- 사진을 성장앨범에 저장하면 그 날짜의 현재 편지도 자동 보관
- 성장앨범에 월별 아빠의 편지 목록과 편지 수 표시
- 사진에 편지가 있는 경우 썸네일 날짜 옆에 💌 표시
- 사진 공유 시 사진·날짜·미션·그 날짜의 편지를 한 장의 이미지로 전송
- 하린은 분홍 꽃·하트 편지지, 서율은 하늘색 별·구름 편지지
- 긴 편지는 글자 크기를 자동 조절하고 너무 길면 말줄임 처리
- 기존 성장앨범 사진 저장 키는 그대로 유지하여 업데이트 시 기존 기록 보존
- 전체 파일 수 9개, 폴더 없음
