# 오늘의 나 V5.4.3

수정 사항
- 설정 화면에 공통 `초기화할 아이` 선택 메뉴 추가
- 박하린 / 박서율 / 두 아이 모두 중 선택 가능
- 아래 초기화 기능을 아이별로 독립 적용
  - 성장앨범
  - 저장 사진
  - 별과 출석
  - 옷장
  - 꾸미기
  - 편지
  - 전체 초기화
- 한 아이를 초기화해도 다른 아이의 기록은 유지
- 저장 사진 초기화는 성장앨범을 지우지 않고 대표 사진만 기본 사진으로 복원
- 전체 초기화도 선택한 아이의 데이터만 삭제
