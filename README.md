# 오늘의 나 V6.0.4 — 휴대폰 뒤로가기 재수정

수정 사항
- 성장앨범 크게 보기에서 브라우저 history 상태 대신 URL 해시(#album-viewer) 사용
- 휴대폰 자체 뒤로가기를 누르면 해시가 제거되면서 크게 보기만 닫힘
- 앱이나 브라우저가 종료되지 않고 성장앨범 화면으로 복귀
- X 버튼도 같은 뒤로가기 흐름으로 동작
- 삼성 인터넷에서 더 안정적으로 동작하도록 hashchange 이벤트 사용
- 기존 좌우 넘기기, 즐겨찾기, 다시 꾸미기, 공유, 삭제 유지
