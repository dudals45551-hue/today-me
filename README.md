# 오늘의 나 V5.6.2 — 홈 화면 앱 아이콘/PWA

변경 사항
- 홈 화면 추가 시 `오늘의 나` 전용 앱 아이콘 표시
- Android 192×192, 512×512 아이콘 추가
- Android Adaptive/Maskable 아이콘 추가
- iPhone Apple Touch Icon 180×180 추가
- 앱 이름을 `오늘의 나`로 고정
- 세로 방향 설치형 PWA 설정
- 실행 시 전용 시작 화면(스플래시) 표시
- 서비스워커와 오프라인 캐시 추가
- 기존 사진, 꾸미기, 성장앨범, 별, 옷장 기능 유지

확인:
https://dudals45551-hue.github.io/today-me/?v=562

기존 홈 아이콘이 남아 있으면:
1. 기존 홈 화면 아이콘 삭제
2. 브라우저에서 위 주소 새로 열기
3. 메뉴 → 홈 화면에 추가
